# configHQshell

A git repo shell for **drafting quick UX work** for **ConfigHQ** — space to create ideas quickly and chat through prototypes with the **UX / UI** team.

This is intentionally lightweight: spin up UI experiments, share links or screenshots, and iterate outside production timelines.

## Getting started

```bash
npm install
npm run dev
```

## Contents (sketch)

- React + Vite shell aligned with ConfigHQ-style layouts where helpful  
- Product drafts (e.g. SFTP Mailbox Manager) as UX-facing references
